🧩 모듈 관리
파이프라인 노드(모듈)를 끼웠다 뺐다 합니다. HTTP 모듈은 사내 시스템 API 요청 하나를 입력칸만 보이는 전용 노드로, 파이프라인 모듈은 만들어 둔 파이프라인을 노드 하나로 포장합니다. 만든 모듈은 ⬇ 내보내기로 .wbmod 파일을 만들어 팀원에게 주고, 받은 사람은 ⬆ 가져오기로 팔레트에 바로 추가합니다.
내 모듈 0
직접 만들었거나 가져온 모듈 — 팔레트 "내 모듈" 칸에 보입니다.
기본 모듈 0
앱에 들어 있는 모듈 — 안 쓰는 건 끄면 팔레트에서 숨겨집니다. 이미 파이프라인에 놓인 노드는 꺼도 그대로 실행됩니다.
모듈 만들기
① 노드 모양 팔레트·캔버스에 이렇게 보입니다
② 입력칸 이 모듈을 쓰는 사람이 노드 설정에서 채우는 칸 — 값에 ${input}·${date} 같은 변수도 쓸 수 있음
이름 (틀에서 {{이름}})표시 이름종류기본값 선택지 (쉼표)연결할 안쪽 노드 설정
③ 보낼 요청 입력칸 값은 {{이름}} 자리에 들어갑니다 (주소는 URL 인코딩, JSON 바디는 따옴표 안에 안전하게)
칩을 누르면 마지막으로 누른 칸(주소·헤더·바디)의 커서 자리에 {{이름}} 이 들어갑니다. 토큰·쿠키는 헤더에 직접 쓰지 말고 비밀값(password) 입력칸으로 — 내보낼 때 자동으로 빠집니다.
초
이름 (${출력변수.이름})JSON 경로 (예: data.docNo · items[0].title)
③ 안쪽 파이프라인 트리거(웹훅·타이머)는 빼고 나머지 노드를 그대로 실행합니다 — 앞 노드 출력은 안쪽 첫 노드의 ${input}
④ 🧪 시험 실행 저장하지 않고 지금 설정으로 한 번 실행해 봅니다
