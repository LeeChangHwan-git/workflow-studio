🍪 로그인 쿠키 넣는 법

회사 게시판처럼 로그인해야 보이는 페이지를 가져오려면, 브라우저가 가진 "로그인 증표(쿠키)"를 Workflow Studio 에도 알려줘야 합니다. 1분이면 됩니다.
크롬·엣지 모두 같은 방법입니다. 이 창은 옆에 띄워 두고 따라 하세요.
⚡ 가장 쉬운 방법 1. 로그인2. F12 → 네트워크3. 새로고침 · 문서 고르기 4. cURL로 복사 → 붙여넣기4-B. 값만 직접 복사5. 확인 문제 해결보안

⚡ 요약 — 이것만 하면 됩니다

  1. 평소처럼 게시판에 로그인하고, 가져올 목록 페이지를 엽니다.
  2. F12 → 위쪽 네트워크(Network) 탭 → F5 로 새로고침.
  3. 필터에서 문서(Doc) 를 누르면 남는 첫 줄(목록 페이지 이름)을 마우스 오른쪽 클릭
  4. 복사(Copy) → cURL로 복사(bash) / Copy as cURL (bash)
  5. Workflow Studio 의 🍪 헤더 칸에 Ctrl+V → 쿠키만 자동으로 뽑혀 들어갑니다. 끝!

1 게시판에 로그인하고 목록 페이지 열기

평소 쓰는 브라우저(크롬/엣지)로 회사 게시판에 로그인한 뒤, Workflow Studio 로 가져오고 싶은 글 목록 화면까지 들어갑니다. 주소창의 주소가 분석기에 넣을 주소입니다.

4B (다른 방법) 쿠키 값만 직접 복사

cURL 메뉴가 없거나 값만 넣고 싶을 때: 그 줄을 왼쪽 클릭 → 오른쪽에 열린 헤더(Headers) 탭 → 아래로 내려 요청 헤더(Request Headers) → Cookie 줄의 값 전체를 드래그해서 복사 → 헤더 칸에 붙여넣기 (앞에 Cookie: 를 안 붙여도 자동으로 붙음).

자주 하는 실수 — ① 「응답 헤더」의 Set-Cookie 를 복사함 (❌, 반드시 요청 헤더의 Cookie) ② 값 일부만 복사함 (긴 값의 끝이 잘림) ③ 이미지·CSS 줄을 골라서 Cookie 가 다름 → cURL 복사 방법을 쓰면 이런 실수가 없습니다.

5 잘 됐는지 확인

분석기에서 불러오기를 다시 누르세요.

  • ✅ 로그인했을 때와 같은 글 목록(또는 내 이름)이 보이면 성공 — 이제 글 제목을 클릭해서 고르면 됩니다.
  • ❌ 로그인 화면이나 "권한이 없습니다", HTTP 401/403 이 나오면 쿠키가 틀렸거나 만료된 것 → 3~4단계를 다시.

🔧 문제 해결

증상원인과 해결
네트워크 탭이 비어 있어요개발자 도구를 연 다음에 F5 로 새로고침해야 기록됩니다. 왼쪽 위 빨간 ● 기록 버튼이 켜져 있는지도 확인.
「문서」를 눌렀더니 아무것도 없어요필터 칸에 글자가 들어 있지 않은지 확인하고, 「전체」를 눌러 맨 위 줄(유형 document)을 찾으세요.
요청 헤더에 Cookie 줄이 없어요로그인이 안 된 상태이거나 다른 줄을 골랐습니다. 로그인 후 목록 페이지에서 다시 F5. (사이트에 따라 「⚠ 임시 헤더가 표시됩니다」가 보이면 캐시 때문 → 「캐시 사용 중지」 체크 후 새로고침)
붙여넣었더니 "Cookie 가 없습니다"cURL 이 아니라 URL 만 복사했거나, 이미지/스크립트 줄을 복사했습니다. 유형이 document 인 줄에서 다시 복사.
어제는 됐는데 오늘 실패해요쿠키(세션)가 만료됐습니다 — 다시 로그인해서 같은 방법으로 새 쿠키를 넣으세요. 로그인 화면의 「로그인 상태 유지」를 켜 두면 오래 갑니다. 타이머로 매일 돌릴 거라면 실패 시 알 수 있게 결과를 확인하세요.
쿠키를 넣어도 로그인 화면이 나와요일부 사이트는 쿠키 외에 Referer 등을 확인합니다. 헤더 칸에 Referer: (목록 페이지가 열리기 직전 주소) 줄을 직접 추가해 보세요. 회사 보안 정책상 IP·기기 확인을 하는 사이트는 막힐 수 있습니다.
로그인 후 회사 SSO 로 여러 번 이동해요상관없습니다 — 최종 목록 페이지의 요청(문서)에서 복사하면 됩니다. 이동 중에 받는 쿠키도 Workflow Studio 가 이어서 처리합니다.
목록이 비어 보여요 (쿠키는 맞는데)목록을 자바스크립트로 그리는 페이지일 수 있습니다. 「문서」 대신 「Fetch/XHR」 필터에서 글 목록 데이터를 주는 요청을 찾아, 그 주소를 HTTP 요청 노드로 가져오는 방법을 쓰세요.

🔒 보안 — 꼭 읽어 주세요

쿠키는 로그인 그 자체입니다. 쿠키를 가진 사람은 비밀번호 없이 내 계정으로 들어갈 수 있습니다.
  • 메신저·메일·문서로 다른 사람에게 보내지 마세요. 화면 캡처에도 값이 찍히지 않게 주의하세요.
  • Workflow Studio 에서는 이 PC의 data 폴더(파이프라인 파일)에만 저장되고, 화면에서는 가려서 보여 주며, 💬 도우미 AI 에게는 *** 로 가려서 보냅니다.
  • 파이프라인을 내보내기(ZIP) 해서 남에게 줄 때는 헤더 칸을 비우고 보내세요.
  • 회사 보안 규정상 자동 수집이 허용되는 게시판인지 확인하고 쓰세요.
※ 그림은 크롬 개발자 도구를 본떠 그린 것입니다 (실제 화면을 캡처하면 로그인 쿠키 값이 그림에 남기 때문). 엣지도 같은 위치·이름입니다. 영어로 된 브라우저는 Network · Doc · Copy · Copy as cURL (bash) · Request Headers 입니다.
