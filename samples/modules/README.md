# 🧩 샘플 모듈 (.wbmod)

worKBench **⚙ 설정 → 🧩 모듈 관리** (또는 파이프라인 편집 화면 팔레트 맨 아래 "🧩 모듈 관리") → **⬆ 가져오기** 로 넣으면
팔레트 **"내 모듈"** 칸에 바로 나타납니다.

| 파일 | 종류 | 하는 일 | 가져온 뒤 할 일 |
|------|------|---------|-----------------|
| `그룹웨어_게시판_글쓰기.wbmod` | HTTP | 시연용 그룹웨어 게시판(`/demo-board`)에 글 올리기 → `${board.글번호}` `${board.주소}` | 노드의 **로그인 쿠키** 칸에 `demo-7f3a91c2` 입력 (비밀값이라 내보낼 때 빠짐) |
| `오늘_날씨.wbmod` | HTTP | Open-Meteo 공개 API 로 지금 기온·습도·바람 → `${weather.기온}` | 없음 (인터넷만 필요, 키 없음) |
| `회의록_폴더_요약.wbmod` | 파이프라인 | 폴더의 Word 회의록 → AI 요약 (안쪽: 파일 가져오기 → AI 에이전트 + Gemini + 지시문) | Gemini 키는 ⚙ 설정 → 공용 키 사용 · 노드의 **회의록 폴더** 칸 확인 |

## 직접 만들기
- **＋ HTTP 모듈 만들기**: 입력칸(예: 제목·내용·토큰) → 요청 주소·헤더·바디 틀에 `{{입력칸}}` → 응답에서 꺼낼 값(`data.docNo`) → 🧪 시험 실행 → 저장
- **＋ 파이프라인으로 만들기**: 원본 파이프라인 고르기 → 입력칸을 안쪽 노드 설정에 연결(예: 폴더 → 파일 가져오기.폴더) → 결과 노드 → 저장
- 만든 모듈 카드의 **⬇ 내보내기** → `.wbmod` 파일 → 팀원이 **⬆ 가져오기**

## 주의
- 토큰·쿠키는 헤더에 직접 쓰지 말고 **비밀값(password) 입력칸**으로 — 내보낼 때 자동으로 비워집니다
- 같은 모듈(같은 id)을 다시 가져오면 **바꿔 쓰기**(그 모듈을 쓰는 파이프라인에 바로 반영) 또는 **사본으로** 중 고름
