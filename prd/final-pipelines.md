## ① 사내 게시판 → 내 직무 관련 글만 쪽지

```
⏰ 평일 08:30 → 🔎 전사 게시판 읽기 → 🤖 내 직무 관련 고르기 → 🔀 관련 글 있나? ─[그 외]→ ✉️ 나에게 쪽지
                                       ↑ Gemini + 📜 "내 직무"         └[관련 글 없음]→ (아무것도 안 함)
```
- **웹 페이지 추출**: `http://localhost:8080/demo-board`, 요청 헤더 `Cookie: GW_SESSION=demo-7f3a91c2`,
  반복 행 `table.board-list tbody tr`, 항목 번호·분류·제목·작성자·날짜·링크(`td.subject a @href`)
- **"내 직무" 지시문**(여기만 고치면 사람마다 다르게): 소속·담당 제품·관심 키워드·관심 없는 것 + 쪽지용 출력 형식, 없으면 정확히 "관련 글 없음"
- **분기**: AI 답에 "관련 글 없음"이 있으면 쪽지를 보내지 않음 (쓸데없는 알림 방지)
- 회사 적용: URL·쿠키·선택자만 실제 그룹웨어 것으로 (🔍 분석기로 클릭해서 고르기, 쿠키는 ❓ 가이드)

**테스트 (▶ 실행)** — 게시판 14건 읽음 → AI 가 **7건** 고름:
OTA 서버 TLS 인증서 교체 · 부트로더 서명 키 HSM 이관 · 센서보드 Wi-Fi 재연결 불량 분석 요청 · MCU SDK 보안 패치(CVE) ·
Rev.D 핀맵 변경 · 양산 펌웨어 굽기 지그 교체 · 빌드 서버 점검 (+ 의무교육 마감은 한 줄 메모).
식당 메뉴·체육대회·주차·부고·마케팅·보험은 제외. 글마다 "왜 관련 있는지 / 할 일 / 🔗 링크". 분기 → 그 외 → 나에게 쪽지 창.
- 첫 시도는 Gemini 응답 지연으로 120초 시간 초과 실패 → 재시도·대기시간 늘린 뒤 성공

## ④ CI 빌드 결과 → 분기 알림

```
🪝 POST /webhook/ci-build {project, branch, status, log} → 🔀 빌드 상태 ─[실패: fail/failure/error/broken]→ 🤖 실패 원인 분석 → ✉️ @FW팀
                                                          ├[성공: success/passed/ok]→ ✉️ 나에게 "🟢 성공"
                                                          └[그 외]→ ✉️ 나에게 "⚪ 알 수 없는 상태 — 확인 필요"
```
- 운영 URL 켜짐 → Jenkins/GitLab CI 의 빌드 후 단계에서 `curl -X POST http://<이 PC>:8080/webhook/ci-build -H "Content-Type: application/json" -d @result.json`
  (지금은 127.0.0.1 에서만 받음 — 다른 PC 에서 부르려면 `server.address` 변경 필요)
- 대소문자 무시 + "다음 중 하나 포함"이라 `FAILURE`, `Failed` 도 실패로

**테스트 (실제 웹훅 3번)**:
| status | 간 쪽 | 결과 |
|--------|------|------|
| `FAILURE` (cert_store.c:142 `ROOT_CA_2026` undeclared) | 실패 | AI: "원인: ROOT_CA_2026 미선언 / 의심 위치: src/ota/cert_store.c:142 / 다음 조치: 정의 추가 또는 ROOT_CA_2024 오타 확인" → @FW팀 |
| `success` | 성공 | "🟢 빌드 성공 — gateway-fw (main) · 20:43" → 나 |
| `ABORTED` | 그 외 | "⚪ 알 수 없는 빌드 상태 "ABORTED" … 확인 필요" → 나 |
나머지 갈래는 모두 "건너뜀".
