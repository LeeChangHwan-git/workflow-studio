# 분기 (`BRANCH`)

## 상태: ✅ 완료 (2026-10-09)

## 목적
값을 규칙으로 검사해 **맞는 쪽 출력으로만** 다음 노드를 실행 (예: 1 포함 → A, 2 포함 → B, 그 외 → C).
규칙 하나 = 노드 오른쪽 출력 하나 + 맨 아래 "그 외". 선택되지 않은 쪽 노드는 "건너뜀".

## 파라미터
| name | label | 기본값 | 설명 |
|------|-------|--------|------|
| `subject` | 검사할 값 | `${input}` | 예: `${webhook.body.type}`, `${page.count}` |
| `rules` | 규칙 | 1 포함 / 2 포함 | `branchRules` — JSON 목록 `[{id, label, op, value, subject?}]`. id = 출력 연결점, label = 출력 이름(화살표에도 표시), subject = 이 규칙만 다른 값 |
| `mode` | 여러 규칙이 맞으면 | 처음 맞는 규칙 하나만 | · 맞는 규칙 모두 |
| `ignoreCase` | 글자 비교 | 대소문자 무시 | · 대소문자 구분 |
| `outputVar` | 출력 변수명 | `branch` | |

출력 값: 들어온 값을 **그대로** 넘김 (다음 노드의 `${input}` 은 분기 전과 같음). 맞은 규칙 이름은 `${branch.matched}`.

## 연산자 (`BranchRules.OPS`)
포함 · 포함하지 않음 · 같음 · 다름(앞뒤 공백 무시) · ~로 시작 · ~로 끝남 · 다음 중 하나 포함(쉼표) · 정규식에 맞음(찾기) ·
비어 있음 · 비어 있지 않음 · 숫자 > ≥ < ≤ = ("1,234", "85점"처럼 숫자 하나면 읽음, 숫자가 아니면 맞지 않음) · 글자 수 > < ·
**식 (고급)** — Spring 식 언어(SpEL)를 **읽기 전용 안전 모드**(`SimpleEvaluationContext.forReadOnlyDataBinding().withInstanceMethods()`)로:
변수 `#value`(글자) `#num`(숫자 또는 null) `#len` `#json`(JSON 이면 Map/List) `#lines`, 연산 `== != > >= < <= and or not matches ?:`, 글자 함수.
`T(...)`·`new ...`·대입은 오류 (클래스 접근·객체 생성 불가). 결과가 참/거짓이 아니면 오류

## 설정 화면 (`BranchRulesField.tsx`)
- 규칙마다: 이름(조건에 맞춰 자동, 직접 바꾸면 유지) · 연산자 · 비교값(연산자별 예시) · "+ 이 규칙만 다른 값 검사" · ↑↓ 순서 · ✕ 삭제
- "그 외" 줄 고정 표시, + 규칙 추가
- **🧪 시험해 보기**: 예시 값을 넣으면 0.4초 뒤 `/api/branch/test`(실행과 같은 판정)로 맞는 규칙을 초록으로, "→ ○○ 출력으로" 표시, 규칙 오류 안내
- **❓ 표현식 설명서**: 별도 창 `/guide/branch` — 동작 방식 · 검사할 값 · 연산자 표(예와 맞음/아님) · 식(변수·연산·예) · 정규식 정리 · 여러 규칙 · 예시 모음 · 자주 묻는 것
- 규칙을 지우면 그 출력의 화살표도 그리지·저장하지 않음

## API
| Method | Path | 설명 |
|--------|------|------|
| `POST` | `/api/branch/test` | `{sample, rules, mode, ignoreCase}` → `{ok, picked:[id], results:[{id,label,matched,error}]}` |
| `GET` | `/api/branch/ops` | 연산자 목록 |
| `GET` | `/guide/branch` | 표현식 설명서 |

## 예시 파이프라인 "분기 테스트 — 1 / 2 / 그 외"
웹훅 `/webhook-test/branch` `{"text":"..."}` → 🔀 1 / 2 나누기 → [1 포함] ✉️ 20231234 · [2 포함] ✉️ 20220567 · [그 외] ✉️ 20190012
- 실측: "주문 1번…" → 1번 쪽지만, "2번 반품…" → 2번만, "기타…" → 그 외만 (나머지 건너뜀)

## 테스트 (`BranchApprovalTest`)
- 맞는 쪽만 실행·나머지 건너뜀, 값 그대로 전달, 합쳐지는 노드는 한쪽만 와도 실행, 그 외, 맞는 규칙 모두 / 처음 하나만
- 연산자(대소문자, 다음 중 하나, 정규식, 숫자 읽기, 비어 있음, 글자 수, 식 — JSON·#num), 안전 모드에서 `T(...)`·`new` 거부, 참/거짓 아님 오류, 시험 API
