# 🧩 모듈 관리 · 내 모듈 (모듈 끼웠다 빼기 / 내보내기·가져오기)

## 상태: ✅ 완료 (2026-10-11)

## 목적
코드 수정·재빌드 없이 노드(모듈)를 **추가·제거**하고, 만든 모듈을 **파일(.wbmod)로 주고받기**.

| 구분 | 무엇 | 비고 |
|------|------|------|
| A. 켜기/끄기 | 기본 모듈·내 모듈을 팔레트에서 숨김/보임 | `settings.json` `modules.disabled` — 이미 놓인 노드는 꺼도 그대로 실행 |
| B. HTTP 모듈 | HTTP 요청 하나를 **입력칸만 보이는 전용 노드**로 (코드 없음) | 사내 결재·메신저·게시판 API 등 |
| C. 파이프라인 모듈 | 만들어 둔 파이프라인을 **노드 하나**로 | 트리거 노드는 빼고 안쪽 노드를 그대로 실행 |
| (D. Java 플러그인 jar) | 미구현 — 가져온 코드가 PC 에서 그대로 실행돼 위험, 필요해지면 검토 | |

## 화면 — `/modules` (⚙ 설정 왼쪽 "🧩 모듈 관리 ↗", 팔레트 맨 아래 링크)
- **내 모듈** 카드: 아이콘·이름·종류(HTTP/파이프라인)·설명·요청 또는 원본·입력칸 수·버전·id·**쓰는 곳**(파이프라인 링크, 다른 모듈 안),
  켜기 스위치, ✏️ 편집·🧪 시험, ⬇ 내보내기, ↻ 원본에서 다시(파이프라인 모듈), 🗑 삭제(쓰는 곳 경고)
- **기본 모듈**: 분류별 목록 + 쓰는 곳 수 + 켜기 스위치
- 상단: ＋ HTTP 모듈 만들기 · ＋ 파이프라인으로 만들기 · ⬆ 가져오기(.wbmod — 같은 모듈이 있으면 [바꿔 쓰기] / [사본으로])
- **만들기·고치기 창**: ① 노드 모양(이름·아이콘 프리셋·색·설명·분류·버전·만든 사람·출력 변수명 + 미리보기)
  ② 입력칸(이름·표시 이름·종류 한 줄/여러 줄/숫자/고르기/비밀값·기본값·선택지 · 파이프라인 모듈은 "연결할 안쪽 노드 설정")
  ③ HTTP: 메소드·주소·헤더·바디(JSON/Form/Text/없음)·`{{입력칸}}` 칩 넣기·시간 제한·2xx 아니면 오류·응답에서 꺼낼 값(이름: JSON 경로) /
     파이프라인: 원본 파이프라인·결과로 쓸 노드
  ④ 🧪 시험 실행 — 저장 전 입력값·앞 노드 출력으로 한 번 실행, 출력 표시

## HTTP 모듈 규칙 (`HttpModule`)
- 입력칸 값(`${...}` 먼저 치환) → 틀의 `{{이름}}`: **주소는 URL 인코딩**, 헤더는 줄바꿈 제거, **JSON 바디는 따옴표 안에 안전하게(이스케이프)**, form 은 URL 인코딩
- 틀에 없는 `{{이름}}` 은 저장 때 거부, 바디 JSON 이 깨지면 실행 때 안내
- 출력: `{ok, status, <꺼낸 값들>, response}` → `${출력변수.꺼낸이름}` (경로 `data.items[0].title`)
- 2xx 가 아니면 오류로 멈춤(선택), 시간 제한 1~300초

## 파이프라인 모듈 규칙 (`PipelineModule` + `PipelineRunnerService.runInline`)
- 저장할 때 원본 파이프라인의 노드·연결을 **모듈 안에 복사**(트리거와 그 화살표 제외) — 원본을 고친 뒤 ↻ 원본에서 다시
- 실행: 입력칸 값 → 연결된 안쪽 노드 설정에 넣음 + `${in.이름}` 변수, 앞 노드 출력 → 안쪽 첫 노드의 `${input}`,
  결과 = 지정 노드(없으면 마지막으로 출력을 낸 노드)의 출력
- 지금 스레드에서 바로 실행, 부모 실행 id 를 그대로 써서 취소·🙋 확인 요청이 부모와 함께 동작, 실행 기록엔 따로 안 남김
- 안쪽 실패 → "모듈 안 [노드 이름] 실패 — 이유", 모듈 안에 모듈은 5단계까지(무한 반복 방지), 자기 자신은 넣을 수 없음
- 엔진 로그 머리표: 내 모듈은 타입 id 대신 모듈 이름 (`[회의록 폴더 요약] 완료`)

## 저장 · 파일
- `{storage}/modules/{id}.json` (id = `MOD_` + 8자리), 노드 타입 등록부가 기본 모듈 다음에 붙임 → 팔레트 "내 모듈", 💬 도우미도 사용 가능
- `.wbmod` = JSON `{format:"worKBench-module", formatVersion:1, exportedAt, secretsRemoved:[…], module:{…}}`
- **내보낼 때 비우는 것**: 비밀값 입력칸 기본값, 이름이 Authorization·Cookie·Token·API-Key·Secret·Password 인 헤더의 값(`{{}}` 를 쓰면 유지),
  파이프라인 모듈 안쪽 노드의 비밀 설정(password·secretTextarea), 원본 파이프라인 id
- 가져오기: 형식·버전 확인, 같은 id 면 409 → 바꿔 쓰기/사본, 안쪽에 이 PC 에 없는 모듈 타입이 있으면 알림
- 지운 모듈을 쓰던 노드는 편집 화면에서 "❓ 없는 모듈 (MOD_…)"로 표시(화면 안 깨짐, 저장해도 타입 유지), 실행 땐 오류

## API
| Method | Path | 설명 |
|--------|------|------|
| GET | `/api/modules` | 기본 모듈(켜짐·쓰는 곳 수) + 내 모듈(쓰는 곳) + disabled |
| PUT | `/api/modules/state` | `{disabled:[타입 id]}` |
| GET/POST/PUT/DELETE | `/api/modules[/{id}]` | 내 모듈 조회·만들기·고치기·지우기(`?force=true` 면 쓰는 곳이 있어도) |
| POST | `/api/modules/{id}/refresh` | 파이프라인 모듈 원본에서 다시 가져오기 |
| GET | `/api/modules/{id}/export` | `.wbmod` 내려받기 |
| POST | `/api/modules/import` | multipart `file` (+ `overwrite` / `copy`) |
| POST | `/api/modules/test` | `{module, values, input}` → `{ok, output, ms}` / `{ok:false, error}` |
| GET | `/api/modules/pipeline-source/{pipelineId}` | 원본 파이프라인 노드·설정 (입력칸 연결용) |

## 테스트 (`CustomModuleTest` — 가짜 API 서버)
- HTTP: 팔레트 등록, URL 인코딩·비밀값 헤더·JSON 이스케이프(따옴표·줄바꿈), 응답 값 꺼내기, 500 → 오류, 틀의 없는 입력칸 저장 거부, 시험 실행
- 내보내기: 비밀 기본값·쿠키 값 제거, 틀·일반 헤더 유지 / 가져오기: 충돌 409·바꿔 쓰기·사본·잘못된 파일 400
- 파이프라인 모듈: 트리거 제외 복사, 입력칸 → 안쪽 노드 설정(변수 치환), 앞 노드 출력 → 안쪽 `${input}`, 결과 노드, 안쪽 실패 위치 표시, 쓰는 곳 있으면 삭제 409
- 켜기/끄기: 중복 제거, 목록에 꺼짐 표시
