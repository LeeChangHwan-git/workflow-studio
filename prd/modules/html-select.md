# 웹 페이지 추출 (`HTML_SELECT`) + 🔍 HTML 분석기

## 상태: ✅ 완료 (2026-10-05)

## 목적
API 없이 **브라우저에서만 보이는** 사내 게시판·웹 페이지에서 글 목록 등을 뽑는다 (HTML 구조를 CSS 선택자로 지정).
선택자를 몰라도 되도록 **분석기**에서 페이지를 보며 원하는 글 제목을 클릭하면 "같은 종류 전부"를 고르는 선택자를 자동으로 만든다.

## 파라미터

| name | label | 기본값 | 표시 조건 | 설명 |
|------|-------|--------|-----------|------|
| `name` | 노드 이름 | `""` | | |
| `source` | HTML 가져오기 | URL에서 가져오기 | | URL에서 가져오기 / 앞 노드 출력(HTML) (예: HTTP 요청 노드로 로그인 후 받은 HTML) |
| `url` | 페이지 주소 | `https://` | URL | `${...}` 가능 |
| `headers` | 요청 헤더 | `""` | URL | `secretTextarea` — 로그인 쿠키 `Cookie: JSESSIONID=...` 등 (AI 도우미에게는 `***`) |
| `picker` | 분석기 | - | | `htmlPicker` — 🔍 분석기 열기 버튼 + 현재 설정 요약 |
| `rowSelector` | 반복 항목(행) 선택자 | `""` | | 게시글 한 줄 (예: `table.board > tbody > tr`). 비우면 문서 전체 |
| `fields` | 가져올 항목 | `""` | | 한 줄에 하나 `이름: 선택자 @속성` |
| `limit` | 최대 개수 | 100 | | 1~5000 |
| `ifEmpty` | 찾은 항목이 없으면 | 오류로 중단 | | 오류로 중단 / 빈 결과로 계속 |
| `outputVar` | 출력 변수명 | `page` | | |

### 가져올 항목 문법
```
제목: td.subject a            ← 글자 (공백 정리)
링크: td.subject a @href      ← 주소 (상대 주소는 절대 주소로)
날짜: td:nth-of-type(4)
번호: @data-no                ← 선택자를 비우면 행 자신
# 주석
```
`@속성`: 생략=글자, `@href` `@src` (절대 주소), `@html`, 그 밖의 속성 이름. 이름에 `:` 불가, 콜론 다음에 선택자.

## 동작
- 행 선택자가 있으면 **행마다** 각 항목 선택자를 행 안에서 찾음(첫 번째). 없으면 문서 전체에서 항목별로 모두 찾아 순서대로 짝지음
- 모든 항목이 빈 행(표 머리글 `th` 줄, 빈 줄 등)은 버림
- 가져오기(`HtmlFetcher`): 문자셋 자동 판별(응답 헤더 → `<meta>` — **EUC-KR** 사내 사이트), 브라우저 같은 User-Agent,
  리다이렉트 중 받은 쿠키 유지(요청마다 새 쿠키 저장소), HTTP/1.1, 최대 5MB, 401/403 이면 "Cookie 를 넣으세요" 안내

## 출력
```json
{ "url": "http://intranet/board/list.jsp", "title": "사내 공지 게시판", "count": 3,
  "items": [ { "제목": "[FW] 부트로더 v2.3 배포", "링크": "http://intranet/board/view.jsp?no=12", "날짜": "2026-10-02" } ],
  "text": "1. [공지] 보안 점검 안내 · 2026-10-01\n2. [FW] 부트로더 v2.3 배포 · 2026-10-02" }
```
AI에게 넘길 때: `${page.text}` (번호 목록, 링크 제외) 또는 `${page.items}` (JSON, 링크 포함).

## 🔍 HTML 분석기 (`components/HtmlAnalyzer.tsx`)
- 노드 설정의 **🔍 분석기 열기** → 전체 화면: 위 주소창 + 🍪 헤더(쿠키), 가운데 페이지, 오른쪽 항목 목록, 아래 미리보기 표
- 페이지 표시: 서버가 받은 HTML 에서 스크립트·`on*` 속성·자동 이동·`javascript:` 링크를 빼고 `<base href>`를 넣어(`/api/html/fetch`)
  **스크립트를 막은 iframe(sandbox)** 에 그림 → 이 화면의 스크립트가 직접 마우스 이벤트를 붙여 강조·클릭 처리 (페이지 이동·폼 전송 막음)
- **클릭 → 선택자 자동 생성**
  1. 링크 안의 글자를 눌렀으면 링크(`a`)를 고름
  2. 첫 클릭: 조상 중 "같은 태그 + 같은 안쪽 경로를 가진 형제"가 가장 많은 것을 **반복 행**으로 판단 (예: `td`가 아니라 `tr`)
     → 행 선택자 = (id 있는 조상까지의 경로) `>` 행 태그(+클래스). 클래스를 넣으면 공지 줄 등 일부만 잡히면 태그만 사용
  3. 항목 선택자 = 행 안에서의 경로 (태그+안정적인 클래스, 같은 모양 형제가 여럿이면 `:nth-of-type`)
  4. 다음 항목(작성자·날짜…)은 같은 행 안의 위치로 계산. 행 밖 요소면 안내
  - 클래스 중 `on/active/selected/odd/even/숫자 많은 것` 등 상태·자동 생성 클래스는 제외
- 페이지 위 강조: 행은 주황 점선, 항목은 색별 칸 / 미리보기 표(브라우저 계산, 30개) / **서버로 확인**(`/api/html/test`, 실제 실행과 같은 jsoup)
- `+ 이 글의 링크 주소도 가져오기`: 같은 선택자로 `@href` 항목 추가
- 프레임(frameset/iframe) 페이지면 안쪽 페이지 주소 목록을 보여 주고 클릭으로 열기 / 내용이 거의 없으면 "로그인 또는 JS로 그리는 페이지" 경고
- **노드에 적용** → url·headers·rowSelector·fields 를 노드 설정에 씀

## 글자 없는 요소(로고·아이콘) 처리 (2026-10-05)
- 문제: 구글 로고(svg)를 클릭 → "글자"로 가져오니 값이 비어 행이 버려짐 → "선택자에 맞는 항목이 없습니다"(원인과 다른 안내)
- 분석기: 글자가 없는 요소를 고르면 가져올 내용을 자동 선택 — src 있으면 이미지 주소, alt/aria-label/title 있으면 그 속성, href 있으면 링크, 아니면 HTML (안내 문구 표시)
- 분석기: 항목마다 "요소 N개 · 값 있는 것 M개" 표시, 요소는 찾았는데 값이 모두 비면 빨간 경고 + **자동으로 고치기**
- 실행 오류 구분: 요소를 못 찾음 vs "요소 N개를 찾았지만 값이 모두 비어 있음 — @src/@html/@alt 지정" (`HtmlExtractor.matchedElements`)

## 🍪 로그인 쿠키 넣기 (2026-10-05)
- **요청 헤더 칸(`HeadersField`)**: 분석기의 🍪 헤더, 노드 설정의 요청 헤더(`secretTextarea` — HTTP 요청 노드도) 공용
  - **붙여넣기 자동 변환**(`headerPaste.ts`): 개발자 도구에서 복사한 **cURL(bash·cmd)**, **요청 헤더 복사**, **쿠키 값만** →
    `Cookie: …` 한 줄로 (+ Authorization 있으면). User-Agent 등 나머지는 버림. 기존 줄과 합칠 때 같은 이름은 교체
  - 값은 기본으로 가려서 표시(●), "값 보기"로 확인, 위에 "🍪 쿠키 N개" 요약
  - **❓ 쿠키 찾는 법** → 별도 창 `/guide/cookie`
- **안내 창 `/guide/cookie`** (`templates/guide/cookie.html`, 독립 페이지 — 앱 탭 수에 안 셈):
  요약 5단계 → 1 로그인·목록 페이지 → 2 F12·네트워크 → 3 F5·「문서(Doc)」 필터·맞는 줄 고르는 법(유형 document, 이름=주소창)
  → 4 오른쪽 클릭·복사·cURL로 복사(bash) → 붙여넣기 → 4B 헤더 탭·요청 헤더·Cookie 값 직접 복사(응답 헤더 Set-Cookie 아님)
  → 5 확인 / 문제 해결 표 8가지 / 보안 주의
  - 그림 6장은 **크롬 개발자 도구를 HTML로 본뜬 그림**(빨간 테두리·번호 설명). 실제 캡처는 로그인 쿠키가 이미지에 남으므로 쓰지 않음
- 분석기에서 내용이 거의 없으면 경고 옆에 "🍪 쿠키 넣기" 버튼
