## 0. 🏠 홈 대시보드
- 왼쪽 위 **wor<KB>ench** 로고(노란 KB = 회사) → "노드를 끌어다 조립하는 작업대"
- 통계 카드(실행 수·실패율·평균 시간), 실행 추이 차트, 파이프라인 5개(트리거·타이머 켜짐 배지, 마지막 실행), 예정된 타이머 탭

## 1. ② 회의록 여러 개 정리 → 확인 → 아웃라인 등록

### 준비
- `바탕 화면\workflow-studio\회의록` 에 Word 회의록 7개 (없으면 "워드 예시 만들어 줘")
- 아웃라인 켜짐 (`http://localhost:3000`), 같은 날 이미 올렸다면 같은 제목 문서의 **내용이 바뀜** (새로 안 생김)

### 진행
1. 파이프라인 열기 → 흐름 설명: 📂 → 🤖 → 🙋(승인/다시/거절 출력, 아래 "수정 AI" 소켓) → 📘 → ✉️
2. **▶ 실행** → 약 20초 뒤 화면 가운데 **🙋 확인 창** 자동 표시 (알림음)
3. 의견 "할 일 표를 담당자별로 묶고, 기한 지난 건 앞에 ⚠️ 지연 표시해 줘" → **🔁 다시** → 2번째 창에서 바뀐 표 확인
4. **✅ 승인** → 오른쪽 아래 쪽지 "올렸습니다 + 링크" → 링크 눌러 아웃라인 `FW팀/회의록/2026년/10월` 확인

### 설명 포인트
- 사람이 결정할 때까지 파이프라인이 **기다림** (창을 닫아도 노드 카드 🙋 확인하기 / 상단 배지로 다시 열기)
- 다시: 수정 AI 가 끼워져 있으면 노드 안에서 고쳐 다시 물음 / 없으면 "다시" 출력으로 흘려 다른 처리
- 거절 → 보류 쪽지(사유 포함), 승인 쪽 노드는 "건너뜀"

## 2. ① 사내 게시판 → 내 직무 관련 글만 쪽지

### 준비
- 브라우저 다른 탭에 `http://localhost:8080/demo-board` (처음엔 로그인 화면 → 아무 값으로 로그인 → 전사 게시판)

### 진행
1. 게시판 탭 보여 주기: "우리 회사 게시판은 브라우저로만 보이고 로그인이 필요하다" (14건, 식당 메뉴·부고·보안 공지가 섞여 있음)
2. 파이프라인 → **🔎 전사 게시판 읽기** 노드 → 🔍 분석기 열기 (클릭으로 항목 고르는 것) · 요청 헤더의 쿠키 + ❓ 쿠키 가이드
3. **📜 내 직무** 지시문 보여 주기 — "여기만 바꾸면 사람마다 다르게"
4. **▶ 실행** (약 20~40초) → 쪽지 창 "📌 오늘의 직무 관련 게시글 (관련 7건 / 전체 14건)"

### 설명 포인트
- 평일 08:30 타이머로 매일 자동 (달력에 예정 표시)
- 관련 글이 없으면 🔀 분기에서 멈춰 쪽지를 안 보냄
- 회사 적용: URL·쿠키·선택자만 실제 그룹웨어 것으로

## 3. ④ CI 빌드 결과 → 분기 알림

### 진행
상단 **HTTP** 메뉴에서 `POST http://localhost:8080/webhook/ci-build` 세 번 (Content-Type: application/json):
```json
{"project":"sensor-board-fw","branch":"feature/ota-cert","status":"FAILURE",
 "log":"src/ota/cert_store.c:142:17: error: 'ROOT_CA_2026' undeclared (first use in this function); did you mean 'ROOT_CA_2024'?"}
```
```json
{"project":"gateway-fw","branch":"main","status":"success","log":"all tests passed (128)"}
```
```json
{"project":"sensor-board-fw","branch":"nightly","status":"ABORTED","log":"Build was aborted by timeout"}
```
파이프라인 화면을 띄워 두면 매번 다른 갈래가 초록 / 나머지는 "건너뜀"으로 보임.

### 보여 줄 장면
- 실패: AI "원인 / 의심 위치 cert_store.c:142 / 다음 조치" → @FW팀 쪽지
- 성공: "🟢 빌드 성공" 한 줄 → 나 / ABORTED: "⚪ 알 수 없는 상태 — 확인 필요" → 나
- 🔀 분기 노드 → 규칙 편집기 · 🧪 시험해 보기 · ❓ 표현식 설명서

## 4. ③ 아웃라인 오늘의 문서 → 팀에 공유
1. **⚙ 설정 → 👥 메신저 그룹** 먼저 보여 주기 (@FW팀 = 나·홍길동, @리더 = 박민수 …)
2. 파이프라인 → ✉️ 노드의 받는 사람 `@FW팀` + 그룹 칩
3. **▶ 실행** (약 10초) → 쪽지 "📊 오늘의 아웃라인 — 문서 N개(컬렉션별) · ⭐ 추천 3개 + 링크 · ✅ 팀이 챙길 일"
4. `/demo-messenger` 쪽지함: 📥 나에게 온 쪽지(창) / 📤 홍길동에게 간 쪽지(그 사람 PC 에 뜨는 것)

## (5) ⑤ 주간 보고서 — ②와 같은 방식, 의견 예: "이슈 맨 위에 OTA 인증서 교체(10/20) 굵게, 할 일은 기한 순" → 승인 → `FW팀/주간보고` + @리더

## 쪽지(메신저) 원리 — 질문 받으면
- 쪽지 노드는 메신저 API 에 **HTTP POST 를 보내는 것**(실제 통신). 지금은 받는 쪽이 이 앱 안의 **시연용 메신저** → **나(20240001)에게 온 쪽지만** 이 PC 오른쪽 아래에 쪽지 창, 다른 사람 것은 쪽지함에 기록만
- 회사 적용: 쪽지 노드의 **API 주소 · 요청 바디(직접 구성) · 인증 헤더**만 회사 메신저 것으로
